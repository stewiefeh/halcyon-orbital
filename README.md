# Halcyon Orbital

A concept marketing site for a fictional private orbital resort. Built from scratch: no frameworks, no build step, no external dependencies.

- `index.html` — single page
- `css/style.css` — all styling, local fonts only (Instrument Serif, Schibsted Grotesk)
- `js/main.js` — nav state, hero parallax, reveals, pinned horizontal voyage with an orbit path that draws as you scroll
- `assets/` — generated imagery
- The inquiry form is a front-end demo: it validates and confirms inline but sends nothing.

Live: https://stewiefeh.github.io/halcyon-orbital/

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000.
